# Session synthesis (after 3–5 sessions)

Use this once you have a small batch of [snapshots](interview-snapshot-template.md).
The goal is to turn individual observations into a short list of changes, each
traceable to a public GitHub issue labelled `user-feedback` (opened with the
[user-feedback issue template](../../.github/ISSUE_TEMPLATE/user-feedback.yml)).

Only include things that were actually observed. If a theme came from one
session, say so; don't round it up into a trend. No quotes unless the
participant consented, and no identifying details.
